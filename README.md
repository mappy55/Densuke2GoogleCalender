# Densuke2GoogleCalender

伝助（[densuke.biz](https://densuke.biz/)）の出欠表を Google Apps Script で定期的に読み取り、自分の Google カレンダーに予定として自動で写す個人用ツールです。
伝助に予定が追加・変更・削除されると、カレンダー側も追加・更新・削除され、メールで知らせます。
少年団やサークルの連絡係など、「伝助で出欠を取ったあと、手でカレンダーに転記している」人向けに作りました。

## はじめに（注意事項）

- **非公式のツールです。** 伝助（densuke.biz）の運営とは関係がありません。伝助には公式 API や iCal 出力が無いため、出欠表の HTML を読んで解析しています。伝助の画面構成が変わると動かなくなる可能性があります。伝助運営から要請があれば公開を取り下げます。
- **自分が参加している伝助ページを、自分のカレンダーに写すための道具です。** 他人のページを収集するような使い方は想定していません。
- **アクセス頻度は控えめです。** 通常は1時間に1回、イベントの直前・直後だけ5分間隔になります（1日あたり数十回程度）。伝助のサーバーに負荷をかけない設計です。
- 取得時の `User-Agent` にはブラウザ（Chrome）の名前を送っています。GAS 既定の User-Agent では出欠表の HTML が正しく取得できなかったための対処です。
- 動作は伝助の出欠表の表形式（ヘッダー行の ◎○△× 列、`M/D(曜)HH:MM-HH:MM タイトル` 形式のイベント名など）に依存します。詳しくは「対応するイベント形式」を参照してください。

## クイックセットアップ

1. [Google Apps Script](https://script.google.com) で新しいプロジェクトを作り、`gas/Code.gs` の内容をすべて貼り付ける
2. 関数 `setupProperties` を実行してスクリプトプロパティの雛形を作る
3. 「プロジェクトの設定 → スクリプト プロパティ」で `DENSUKE_URL`・`CALENDAR_ID`・`TARGET_MEMBER` を自分の値に書き換え、`ENABLED` を `true` にする（チームの共有カレンダーに入れる場合は `TARGET_MEMBER` を空にする。後述の「チームモード」参照）
4. 関数 `testScheduledSync` を実行して動作を確認する（初回は権限の許可が必要）。右上の「デプロイ」は不要
5. 関数 `setupHourlyTrigger` を実行して毎時の自動同期を有効にする

## 2つの使い方（個人モード / チームモード）

`TARGET_MEMBER` の有無で動作が切り替わります。

| | 個人モード（`TARGET_MEMBER` あり） | チームモード（`TARGET_MEMBER` 空） |
|---|---|---|
| 想定 | 自分（や自分の子）の予定として自分のカレンダーに入れる | チームの共有カレンダーに全員の予定として入れる |
| イベントのタイトル | `○ 練習@○○小`（自分の回答記号が先頭に付く） | `練習@○○小` |
| 説明欄 | 「あなたの回答」「メンバー」の2行が先頭に入る | 入らない |
| リマインダー | 自分が × のイベントには付けない | すべてのイベントに付ける |
| 出欠人数・メンバー一覧・コメント | 入る | 入る（同じ） |

途中でモードを切り替えると、次回の同期でタイトルが書き換わります（イベントは作り直されません）。

# GAS マニュアル

## 機能一覧

### 同期機能
- **自動同期**: トリガーで定期的に伝助→カレンダー同期
- **追加**: 新規イベントをカレンダーに追加
- **更新**: 既存イベントのタイトル・日時を更新
- **削除**: 伝助から削除されたイベントをカレンダーから削除
- **動的同期頻度**: イベント前後で自動的に同期頻度を調整
  - **通常**: 1時間ごと（毎時00分）
  - **イベント前後**: 5分ごと（開始1時間前～開始後20分）
  - 完全自動で切り替わり、重複トリガーなし

### 通知機能
| イベント | 通知 | メール件名 |
|---------|------|------------|
| 新規追加 | あり | 📅 新規イベント追加: [タイトル] |
| タイトル変更 | あり | 📝 イベント更新: [タイトル] |
| 削除 | あり | 🗑️ イベント削除: X件 |
| 出欠変更のみ | なし | なし |
| エラー発生 | あり | ⚠️ 自動同期エラー |

> **スマート通知**: 同一日付で削除と追加が発生した場合、「更新」として通知1通のみ送信!
> すべての通知メールに**伝助URL**が含まれ、タップで直接アクセス可能！

#### 通知メール例

**新規イベント追加：**
```

詳細:

あなたの回答: ○
メンバー: XX.ユーザー名
...
```

**イベント更新（タイトル変更時）：**
```

本文:
イベントが更新されました。

```

> タイトル変更時は「削除＋追加」ではなく「更新」として通知されます

**イベント削除：**
```

本文:
以下のイベントが伝助から削除されたため、カレンダーからも削除されました。

- × 1/26(日)09:00-12:00 試合@△△公園
```

### リマインダー
| 出欠回答 | リマインダー |
|---------|-------------|
| ◎ ○ △ - | 1日前 + 1時間前 |
| × (欠席) | なし |

### 対応するイベント形式
| パターン | 例 | 展開 |
|---------|-----|------|
| 単日 | `1/20(月)15:00-17:00 練習@○○小` | 1件 |
| 終日 | `1/20(月) 練習@○○小` | 1件（終日） |
| 絵文字入り | `1/31(土)🟥🟨14:30-17:00 練習@○○小` | 1件（絵文字保持） |
| 日付範囲 | `3/20～22 合宿` | 3件（3/20, 3/21, 3/22） |
| または | `3/20～21または21～22 学年合宿` | 3件（3/20～3/22） |
| 上記、 | `1/18(日) 上記、自転車引率当番` | 前行の時間を引き継ぎ |


## セットアップ

### 1. GASプロジェクトを作成

1. [Google Apps Script](https://script.google.com) を開く
2. **新しいプロジェクト** を作成
3. `gas/Code.gs` の内容をすべてコピー＆ペースト

### 2. スクリプトプロパティを設定

1. GASエディタで関数を `setupProperties` に選択
2. **▶ 実行** をクリック（初期テンプレート作成）
3. 左メニューの ⚙️ **プロジェクトの設定** をクリック
4. 下部の「スクリプト プロパティ」で以下を設定：

| プロパティ | 値 | 説明 |
|-----------|-----|------|
| `ENABLED` | `true` | 自動同期を有効化 |
| `DENSUKE_URL` | `https://densuke.biz/list?cd=XXXXXXXX` | 伝助URL |
| `CALENDAR_ID` | `primary` | カレンダーID。共有カレンダーは「設定と共有 → カレンダーの統合 → カレンダー ID」の `xxxxx@group.calendar.google.com` |
| `TARGET_MEMBER` | `XX.ユーザー名` | 対象メンバー名（空にするとチームモード） |

> コードを編集せずに設定変更が可能です

### 3. テスト実行

1. GASエディタで関数を `testScheduledSync` に選択
2. **▶ 実行** をクリック
3. 初回は権限の許可を求められます → **許可**
4. **実行ログ** で結果を確認

### 4. トリガーを設定

#### 方法A: 毎時00分付近で実行（推奨）

1. GASエディタで関数を `setupHourlyTrigger` に選択
2. **▶ 実行** をクリック
3. 初回は権限の許可を求められます → **許可**
4. 実行ログに「✅ Hourly trigger set!」が表示されれば成功

> この方法だと毎時00分付近（±15分）で実行されます

#### 方法B: 手動でトリガーを設定

1. GASエディタの左メニューで **⏰ トリガー** をクリック
2. **+ トリガーを追加** をクリック
3. 以下を設定：
   - **実行する関数**: `doScheduledSync`
   - **イベントのソース**: `時間主導型`
   - **時間ベースのトリガーのタイプ**: `時間ベースのタイマー`
   - **時間の間隔**: `1時間ごと` など
4. **保存**

> 注意: この方法だと設定した時刻からの間隔で実行されます（例: 10:22に設定すると毎時22分頃）

#### トリガーを削除する場合

1. GASエディタで関数を `removeAllTriggers` に選択
2. **▶ 実行** をクリック

## 同期の仕組み

### イベントID
- 形式: `densuke_YYYYMMDD_[タイトルハッシュ]`
- タイトルのハッシュで同一日の複数イベントを識別
- カレンダーイベントの説明欄に `[DENSUKE:xxx]` タグとして保存

### 削除判定
- 今日から1年後までのイベントが対象
- 過去のイベントは削除対象外（履歴として残る）

### HTMLエンティティ対応
- `&nbsp;` などのHTMLエンティティを自動デコード
- 絵文字（🟥🟨など）は保持

## トラブルシューティング

### 「カレンダーが見つかりません」エラー
- スクリプトプロパティの `CALENDAR_ID` が正しいか確認
- プライマリカレンダーは `primary`
- 共有カレンダーは Google カレンダーの「設定と共有 → カレンダーの統合 → カレンダー ID」を使う（`xxxxx@group.calendar.google.com` の形）
- そのカレンダーに対して自分に編集権限があるか確認

### 「権限がありません」エラー
- GASの実行時に権限を許可したか確認
- 「高度な設定」→「安全でないアプリのアクセスを許可」

### 通知メールが届かない
- Gmailの迷惑メールフォルダを確認
- GASの実行ログでエラーがないか確認

### メンバーが見つからない
- スクリプトプロパティの `TARGET_MEMBER` が伝助のメンバー名と一致しているか確認
- 実行ログに「WARNING: Target member not found」が出ていないか確認

### スクリプトプロパティが反映されない
- プロジェクトの設定 > スクリプト プロパティ で値を確認
- `setupProperties()` を再実行して初期化

### 時間付きイベントが終日になる
- 伝助のイベントに時刻パターン（例: `15:00-17:00`）が含まれているか確認
- 絵文字やスペースが入っていても正しく解析されます

### イベントが重複する
- 古いIDでイベントが作成されている可能性
- 一度カレンダーのDENSUKEイベントを削除して再同期
